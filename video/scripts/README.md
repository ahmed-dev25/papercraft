# Small Lessons - scripts

The first three films are written by hand. They set the bar, and they become the few-shot
examples for the planner. Every later episode is judged against these.

## The rules (apply to every script)

1. **One concrete metaphor, held all the way through.** A lamp is a person who only takes. A rope is
   an obligation. A wall is a defence. Never swap the meaning mid-film.
2. **One turn.** Want -> cost -> turn -> one line. Eight beats, 75-100 seconds.
3. **The last line is the only line that speaks to the viewer.** Everything before it is story.
4. **Every sentence must be filmable.** No abstractions, no "in today's world", no quotes.
5. **Text is on screen, so it is short.** <= 14 words, one sentence, sentence case.
6. **Quiet, not low-stakes.** The moth loses a wing. The boat loses the harbour. The cost is what
   makes the last line land.
7. **No advice until the last line.** No second-person command earlier. At most one exclamation in
   the whole film (usually none).

## The three-question test

- Can every sentence be filmed?
- Is the metaphor consistent?
- Does the last line add something the images did not say, without explaining them?

If a script fails one, it is not ready.

## Titles are characters, not commands

Good: *The Moth Who Refused the Lamp*, *The Boat That Held the Rope*, *The Wall With a Door In It*.
Bad: *Let Go of What Hurts You*, *Stop Playing Small*, *Your Comfort Zone Is Killing You*.

A title should make someone ask "what happened?" - not tell them what to think.
